# Credits

Each asset folder under `web/src/assets/` has a README with its source and licence.

- Character animations and the Y Bot rig: **Mixamo** (https://www.mixamo.com, Adobe),
  converted to one game-ready file by `tools/assets/convert-mixamo.mjs`. The raw downloads
  are kept locally, not in git.
- Hand-tracking model: **MediaPipe** `hand_landmarker.task` (Google, Apache License 2.0).
- Everything else (the cast, the skyline and set dressing, music, sound effects, shell cards)
  is original work built in this repository by the scripts in `tools/assets/`.
